# Asynchronous AI Image Generator

Асинхронная микросервисная система для генерации изображений с использованием нейросетей (HuggingFace Stable Diffusion). Проект демонстрирует реализацию паттернов отказоустойчивости, работу с брокерами сообщений и контейнеризацию приложений.

## Архитектура

Система состоит из независимых компонентов, взаимодействующих через очередь сообщений:

1. **API Gateway (Go):** Принимает HTTP-запросы от клиента, проводит первичную валидацию и асинхронно ставит задачу в очередь (Non-blocking I/O).
2. **RabbitMQ:** Брокер сообщений. Обеспечивает персистентность задач и гарантированную доставку (Durable queues), предотвращая потерю данных при падении воркеров.
3. **AI Worker (Python):** Фоновый сервис, потребляющий задачи из очереди. Осуществляет взаимодействие с HuggingFace API для генерации изображений и сохраняет артефакты в локальную файловую систему.
4. **PostgreSQL:** Реляционная база данных для персистентного хранения и отслеживания статусов задач (`pending`, `done`, `error`).

## Стек технологий

* **Backend:** Golang, Python 3
* **Infrastructure:** Docker, Docker Compose
* **Message Broker:** RabbitMQ
* **Database:** PostgreSQL
* **AI Integration:** HuggingFace API (Stable Diffusion XL)

## Запуск проекта локально

1. Склонируйте репозиторий.
2. Создайте директорию `images` в корневой папке проекта (директория монтируется в контейнер для сохранения результатов).
3. Укажите ваш HuggingFace API токен в файле `docker-compose.yaml` (переменная окружения `HF_TOKEN`).
4. Выполните сборку и запуск контейнеров:
   ```bash
   docker-compose up --build
   
## Использование API

Пример отправки задачи на генерацию изображения через PowerShell:

```powershell
Invoke-RestMethod -Method Post -Uri "http://localhost:8080/task" -ContentType "application/json" -Body '{"payload": "cyberpunk cat in neon city"}'
```

В качестве ответа API вернет уникальный идентификатор задачи (Task ID). Фоновый воркер асинхронно обработает запрос и сохранит итоговое изображение в локальную директорию /images.
